## Фактический браузерный сценарий

Встроенный Chromium,1440x1024 и390x844:

1. Телефон+пазлы→варианты→перемещение→поворот→дубликат→исходный S→фоновая роль→порядок→скачанный SVG. Проверено3группы,308path,0image, исходные S node ID, один общий scale.
2. Undo/Redo, удаление и открытие ранее скачанного JSON восстанавливают3предмета и custom-палитру. Перезагрузка сохраняет сцену.
3. Импорт custom JSON палитры, повторная смена оригинальных палитр; повреждённый JSON отклонён, текущая палитра сохранена. PNG реально скачан,1200x675.
4. Узкий390px:9:16, названия «книга, лампа, ручка»→сборка→скачанный SVG; горизонтального переполнения после исправления нет.
5. Локальный запрос «Сохранить деньги на будущую учёбу»→book/wallet/coin→принятие→поворот. Следующий неподдерживаемый «Рецепт борща» оставляет текущую сцену и поворот.
6. Настоящий бесплатный OpenRouter ответ получен в редакторе. Во время другого облачного запроса повёрнут предмет: поздний ответ не подменил сцену. Облачное предложение принято и экспортировано отдельно; ключ не попал в браузер.
7. Три SVG-примера скачаны кнопкой приложения:105/212/244path,0image. Скриншоты соответствующих сцен в docs/editor-*.jpg.

[Реальные HTTP/model smoke результаты](evidence/local-http-smoke.json):11/11 после исправления регрессии выбора близких тем и JSON-сериализации.
