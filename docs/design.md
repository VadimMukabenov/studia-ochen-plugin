# Собрано: согласованный контракт

Обычный development-плагин Figma с локальным помощником, полностью собираемый Docker Compose. Пользователь 21.11 согласовал бесплатный CPU-вариант и потребовал запуск одной командой для проверяющего. Команда `docker compose up --build` собирает плагин, скачивает публичную модель в постоянный volume и запускает локальную страницу с ZIP/инструкцией/проверкой семантики. Нужен Docker Compose; Python/Node/GPU/платный API не нужны. Единожды импортировать manifest в Figma Desktop нужно вручную. Первое скачивание требует интернета; после кэширования модели запросы работают локально. Учетка и редактируемая копия исходной библиотеки нужны для создания native layers.

Два режима: точные названия до 4 предметов (без помощника) и свободный текст по смыслу. Второй — retrieval через multilingual-e5-small ONNX CPU по описаниям 10 семейств, не LLM-генерация картинки или универсальный разбор сложных команд. Выход модели — только allowlisted IDs, до 3. Неоднозначный запрос отклоняется. Метрики сходства не являются вероятностью. Ошибка/отсутствие модели показываются явно. Геометрия и раскладка детерминированы.

40 исходных групп в source/catalog.json: 10 семейств × S/L × главный/фон. Выход — только native vector clones на отдельной странице. Единый масштаб всей сцены сохраняет относительные размеры; внутренние пути не меняются. Три формата, свой размер, 3 раскладки. Роль фонового объекта меняется заменой на настоящий исходный вариант. До 12 предметов после дублирования. Перемещение на холсте Figma; поворот/дубль/удаление/порядок доступны также в UI. Исходники и чужие сцены не модифицируются.

Три исходных палитры и JSON-импорт 8 ролей (3 фоновых, ink, 3 предметных, paper). Фон холста берётся только из фоновой части. Исходная схема определяется по paint исходника; неоднозначные роли отклоняются. Повторная перекраска использует записанные исходные роли, а не ближайший цвет предыдущей палитры. Скрытые операнды boolean сохраняются. Native SVG export проверяет принадлежность, масштабы и отсутствие растров/чужих слоёв; provenance в metadata.

Архитектура: code.ts pure core + sandbox adapter; ui.html DOM/message bridge + fetch loopback helper; helper/server.py ONNX tokenizer/mask pooling/L2 normalization + HTTP; Dockerfile multi-stage Node build + Python CPU; compose.yaml loopback port + persistent model volume. Model revision pinned, large files verified SHA256. No artwork sent to model and no prompt logging. Classic plugin network whitelist allows only local helper in development. MCP used for source audit/native evidence, not required by reviewer at runtime. Hosted starter resource 48d9ee06-2cca-45cc-a062-a5d6d0f76f8b is superseded and not a deliverable.

Граница целостности: исходная неизменённая полная копия доверенная при первом использовании; fingerprint структуры/геометрии фиксируется на первом чтении и после клонирования. Последующие изменения исходников, вложенные новые векторы и правки внутренних путей выходных объектов обнаруживаются. Независимого сохранённого hash всех исходных путей до первого использования пока нет; ранее испорченную библиотеку полностью распознать нельзя.
