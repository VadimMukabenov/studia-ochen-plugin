# Сравнение с ориентиром

Ориентир: [GMANCO77/figma-illustration-composer](https://github.com/GMANCO77/figma-illustration-composer), публичный README и доступное веб-приложение просмотрены22ноября2026. Чужой код, стиль и ассеты не переносились. Это сравнение доступных функций, не место среди всех кандидатов и не независимое соревнование качества.

| Проверяемая вещь | Ориентир | Собрано |
|---|---|---|
| Редактор в браузере | Есть | Есть, свой интерфейс с большим холстом и библиотекой справа |
|40вариантов, S/L, палитры,3раскладки|Заявлены и видны основные элементы|Все40 проверены по исходным путям и геометрии|
|Перемещение, поворот, слои, undo, JSON, SVG|Заявлены|Проверен полный браузерный сценарий с реальными скачанными файлами|
|Смысловой AI|Облачный DeepSeek за сервером автора|Бесплатный онлайн OpenRouter без ключа посетителя; дополнительно автономная CPU-модель|
|Первый быстрый просмотр|Веб-приложение|Редактор с AI по ссылке без установки/ключа; также локальный комплект|
|Полный локальный запуск без регистрации|Есть source-инструкция; готовую offline-доставку здесь не подтверждали|Готовый Compose-комплект с моделью внутри, START и две CPU-архитектуры|
|Дополнительный экспорт|SVG/JSON по README|SVG/JSON и PNG|
|Сборка по смыслу и ручные правки|Проверен прямой путь к композиции|Одна кнопка → готовая композиция; отмена, защита от позднего ответа, ошибка сохраняет сцену. Подтверждение только при явно слабом результате|

Сильные стороны нашего решения — бесплатный автономный полный запуск, проверяемые оригиналы, удобный законченный редактор, дополнительные способы экспорта и прозрачные ограничения AI. С 24 ноября онлайн-путь также доступен без установки: GitHub Pages → Cloudflare Worker → бесплатный OpenRouter. [Реальный сценарий](evidence/public-ai-2026-11-24.json). Облачное качество не объявляем выше: в бесплатной модели ответы меняются; локальный retrieval ограничен библиотекой и семантическими примерами.

Цель «не хуже и немного лучше» принята как сопоставимый основной сценарий плюс доказуемые полезные отличия, а не обещание объективного превосходства по вкусу или неизвестного рейтинга кандидатов.
