Собрано

Помощник для конструктора иллюстраций в Figma.

● Модель готова

multilingual-e5-small работает на CPU. Запросы остаются на этом компьютере. Этот экран проверяет подбор предметов; векторы создаёт плагин в Figma.

Подбор сравнивает смысл запроса с описаниями 10 семейств. Он не рисует новые предметы и может ошибаться в метафорах.

Запустить в Figma

  1. Скачать плагин ↓ Распакуйте ZIP.
  2. В Figma Desktop: Plugins → Development → Import plugin from manifest… → выберите распакованный manifest.json.
  3. Откройте файл с библиотекой с правом редактирования или его копию в Drafts.
  4. Plugins → Development → «Собрано». Выберите режим, запрос, формат и палитру. Нажмите «Собрать».

Пример JSON-палитры · Остановить помощник: docker compose down.

После импорта плагина повседневный запуск требует одной команды Docker Compose. Режим по названиям работает и без контейнера.
