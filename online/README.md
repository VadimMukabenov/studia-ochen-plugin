# Публичный AI для «Собрано»

Статус 24.11.2026: код и тесты готовы; публикация в личный Cloudflare и включение на основном сайте ещё не подтверждены. Изменения готовятся в ветке `codex/public-ai`. Основная ссылка редактора остаётся https://vadimmukabenov.github.io/studia-ochen-plugin/ .

GitHub Pages загружает редактор; этот Cloudflare Worker выполняет `/health` и `/resolve`. После включения посетителю не нужны аккаунт, ключ или Docker. Локальный комплект продолжает работать самостоятельно.

Секрет `OPENROUTER_API_KEY` должен храниться только в production secrets Cloudflare, а не в исходниках, GitHub Actions или браузере. Модель `particle-ai/particle-1:free`; сервер отклоняет платные идентификаторы и задаёт `provider.max_price` равным нулю. На 24.11.2026 в официальном каталоге OpenRouter бесплатного DeepSeek нет.

Ключ демо имеет денежный лимит $0 и срок действия до 22.12.2026. Без пополнения OpenRouter даёт общий лимит бесплатных запросов; доступность модели и квота не гарантируются. При ошибке редактор показывает причину, сохраняет композицию и оставляет ручную сборку.

Сервер проверяет origin, размер запроса, каталог и ответ модели; явно названные предметы подбирает без вызова AI. Ответы кэшируются на час в памяти изолята (до 200 записей). Ограничение на IP: 12 AI попыток в сутки и пауза 5 секунд, также в памяти изолята. Это защита от случайного повторения, а не глобальная распределённая квота: перезапуск или другой изолят сбрасывает счётчики. Общую денежную безопасность обеспечивают нулевой лимит ключа и запрет платных моделей. Публичный endpoint предназначен для тестового, не для неограниченного production-трафика.

Проверки и сборка:

```sh
node --test online/tests.mjs
cd online
bash scripts/build.sh
node scripts/validate-artifact.mjs
```

Для прямого развёртывания используется `wrangler.jsonc` и официальный Wrangler 4.167.0:

```sh
cd online
npx wrangler@4.167.0 login
npx wrangler@4.167.0 deploy
npx wrangler@4.167.0 secret put OPENROUTER_API_KEY
```

Ключ вводится в секретное приглашение, не в исходники. Для собственного аккаунта также замените публичный адрес API в `web/app.mjs` и разрешённый origin в Worker. GitHub Pages публикует папку `web` существующим workflow, который дополнительно проверяет контракт Worker.

Опциональные `.openai/hosting.json`, `scripts/build.sh` и `scripts/validate-artifact.mjs` относятся к первоначальному размещению через Sites. Этот вариант вернул настоящий бесплатный ответ AI, но его домен не разрешается через DNS на авторском компьютере; он не принят как проверенная production-доставка. Локальная DNS-проблема затрагивает также workers.dev; это отдельная настройка компьютера, а не повод менять основную ссылку GitHub Pages.
