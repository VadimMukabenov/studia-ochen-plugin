# Визуальный прототип «Собрано»

Открыть index.html обычным браузером. Всё встроено, сеть и Figma для просмотра не нужны. Внутри — представление будущего плагина рядом с холстом, а не рабочая интеграция с Figma.

Работают переключение «По смыслу / По предметам», три примера запросов, три формата/варианта компоновки, три палитры, импорт JSON через «Своя», выбор/перетаскивание/поворот/дублирование/удаление/порядок предметов и формирование SVG для скачивания. Неизвестный запрос даёт ошибку. Семантический подбор использует текущий словарь из настоящего ядра плагина; это не LLM.

Семь реальных исходников из пользовательской копии Figma экспортированы локальным MCP в assets/. Исходные группы и пути не перерисованы. Скачанный export содержит служебный фон родительской секции (rect + два path): предпросмотр убирает эту оболочку и оставляет вложенную исходную группу предмета.

Ограничения этого быстрого прототипа: только L, 7 из 10 семейств; фоновые роли пока демонстрируются монохромной перекраской, а не отдельными подготовленными вариантами. Рабочий плагин использует отдельные оригинальные S/L и главный/фоновый IDs. Нативный Figma файл прототип не изменяет. Прототип не является завершённым тестовым заданием.

Проверено через CUA в браузере: отрисовка исходных векторов, оба режима, переключение палитры, выбор объекта, дублирование/поворот/удаление, адаптация к узкому и широкому окну. При проверке скачивания статус обновился, но browser download observer завис: факт получения файла этим наблюдателем не подтверждён. Сам SVG формируется в клиентском коде без растра. Тестирование реального размещённого plugin UI ещё впереди.
